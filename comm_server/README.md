# Communication Server/Client

This is an example imlementation of communication server and client with [qec_camp_1d_rep_code](https://github.com/ysuzuki-qc/qec_camp_1d_rep_code).

## Setup Example and Execution Commands

Interfaces and addresses are examples, therefore use your appropriate values.

```
 +--------------------------+        +----------------------------+       +------------------------+
 | Comm. client PC          |        | Comm. server PC            |       | MFF sender (KR260)     |
 |                          |        |                            |       |                        |
 |  eno1: c8:7f:54:a9:28:fe |--------| wlo1: 64:49:7d:f3:ac:c3    |       |                        |
 +--------------------------+        |                            |       |                        |
                                     |  enp1s0: 7c:83:34:b9:b1:f2 |-------| eth: 00:1b:1a:ff:ff:00 |
                                     |          10.0.0.219/8      |       |      10.3.0.240/8      |
                                     +----------------------------+       +------------------------+
                                                    |
                                                    |
                                              +-----------+
                                              | record(*) |
                                              +-----------+
```

On Comm. client PC,

```bash
$ python3 comm_client.py --interface=eno1 \
                         --dst-mac=64:49:7d:f3:ac:c3 \
                         --src-mac=c8:7f:54:a9:28:fe \
                         --backend-mac=7c:83:34:b9:b1:f2 \
                         --command=kick
```

`commnad` is `kick` or `reset` or `backend`.


On Comm. server PC,

```bash
$ python comm_server.py --interface=wlo1 \
                        --target=10.3.0.240
```

`MFF sender` sends measurement frames to `backend-mac` host.
